try_files 实验

前端路由没有对应的文件，也能返回页面。

当前浏览器路径是 /app/。服务器上并不存在这个路径对应的 文件，但 try_files 把它回退到了 /app/index.html。

试试这些地址

/app/users/42 · /app/orders/2026 · /app/settings/profile

配置在做什么

location /app/ {
    try_files $uri $uri/ /app/index.html;
}

nginx 先找真实文件，再找目录，最后把请求内部转发到 /app/index.html。 浏览器地址栏不会变，前端路由因此可以接管路径。
