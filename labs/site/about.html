关于实验 SPA 回退 location 演示

实验说明

这是一个故意保持简单的站点。

页面全部是静态文件，没有构建步骤，也不依赖外部字体或 CDN。这样可以把注意力放在 nginx 如何处理请求上，而不是前端工具链。

你会在这里看到什么

  • 静态文件、目录索引和自定义 404 页面。
  • location 的精确匹配、前缀匹配和正则匹配差异。
  • SPA 的 try_files 回退。
  • 缓存在 CSS/JS 上的响应头。
  • 到上游 API、HTTPS、限速和缓存的入口。

安全边界

仓库里的证书是自签名证书，私钥只用于本机实验；.env 和 labs/nginx/certs/ 下的生成物都不应提交到版本库。限速、访问控制和 TLS 配置是为了教学，不构成生产环境的安全方案。

建议的阅读方式

先按 README 的学习路径读工作模型和配置模型，再打开对应章节的实验。每章末尾有练习， 先自己预测结果，再用 curl -i 或日志核对。
