learnNginx · 静态站点实验

把一次 HTTP 请求，拆成可以观察的几步。

这个站点由 nginx 直接提供静态文件。下面的入口分别演示反向代理、负载均衡、 HTTPS、限速和缓存。先打开浏览器开发者工具的 Network 面板，再逐个访问。

观察优先

不要只看“能不能打开”

教程里的每条命令都尽量配一个可验证的结果。打开页面前后，比较响应头、上游实例名、 状态码和日志时间，才能把配置和实际行为对上。 

curl -i http://localhost:8080/
curl -i http://localhost:8081/api/
curl -s http://localhost:8082/api/ | grep instance
curl -k -i https://localhost:8443/
